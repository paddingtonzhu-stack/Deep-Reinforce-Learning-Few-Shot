# ViZDoom few-shot adaptation poster

This A2 poster uses the official Deep Machine Learning course template from:

https://github.com/dml-cth/deep-machine-learning/tree/master/poster-template

## Build

Compile `main.tex` with XeLaTeX or Tectonic from this directory. The checked-in
`main.pdf` is the submission-ready output.

- One page
- A2 portrait
- 420 x 594 mm
- 1189.98 x 1683.78 PDF points

The Chalmers layout, colors, typography, and template files are preserved. The
content, native TikZ figures, and FPS illustration describe the ViZDoom
